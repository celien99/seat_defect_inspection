# 工业视觉系统设计与选型指南

以下内容面向产线级缺陷检测场景，按系统设计的自然顺序组织。

---

## 1. 光源 —— 系统成败的第一因素

> 打光决定图像的上限，算法只是在逼近这个上限。

### 1.1 光源类型与适用场景

| 光源类型 | 特点 | 适用场景 |
|----------|------|----------|
| **环形光** | 同轴照射，均匀无影 | 平面缺陷（划痕、凹坑）、字符识别 |
| **条形光** | 方向性强，可组合 | 大面积平整表面、长条形工件 |
| **穹顶光（漫反射）** | 全方位均匀照明，消除反光 | 曲面、高反光金属件、弧形表面 |
| **背光** | 工件在光源和相机之间 | 轮廓测量、尺寸测量、孔位检测 |
| **同轴光** | 光线与镜头光轴平行 | 镜面/高反光平面（玻璃、抛光金属） |
| **偏振光** | 配合偏振片消除镜面反射 | 高反光表面纹理检测 |
| **紫外/红外光** | 激发荧光或穿透表层 | 胶水检测、涂层缺陷、隐形码读取 |

### 1.2 打光的核心原则

**（1）区分"需要看到的"和"需要压制的"**

根据缺陷类型选择光的入射角度：
- **低角度光（掠射）**：表面凹凸、划痕、纹理 → 光几乎平行于表面
- **高角度光（明场）**：表面颜色差异、印刷缺陷 → 光垂直于表面
- **背光**：边缘轮廓、贯穿孔 → 相机对着光源

**（2）对比度优先于亮度**

不是越亮越好，关键是缺陷区域与正常区域的灰度差异。选择波长（颜色）可以进一步增强对比度：
- 红色工件上的蓝色缺陷 → 用红光，缺陷变暗
- 绿色PCB上的铜箔 → 用绿光，铜箔变亮

**（3）消除环境光干扰**

产线上必须使用遮光罩封闭检测工位，或用频闪控制器在极短时间内（μs级）过驱动LED，曝光时间内压倒环境光。

### 1.3 控制器选型要点

- **常亮 vs 频闪**：运动检测必须用频闪（overdrive），静止检测可用常亮
- **模拟 vs 数字**：数字控制器可编程调节亮度、触发延迟、脉宽
- **通道数**：多角度打光时需要多通道独立控制

## 2. 相机选型

### 2.1 面阵 vs 线阵

|  | 面阵相机 | 线阵相机 |
|--|---------|---------|
| 适用 | 静止或慢速运动（<0.5m/s） | 高速连续运动（卷材、传送带） |
| 分辨率 | 一次曝光获取整幅图像 | 逐行扫描拼接 |
| 成本 | 低 | 高（需编码器+高均匀光源） |
| 标定 | 简单 | 需精确同步编码器 |

**判断依据**：工件在曝光时间内移动距离 < 1/3 像素尺寸 → 面阵可用，否则上线阵。

### 2.2 传感器关键参数

**（1）分辨率计算（核心公式）**

```
分辨率 = 视野长边 / 精度需求 × 3（冗余系数）
```

例：视野 300mm × 200mm，需检测最小缺陷 0.3mm
- 每个缺陷至少占 3 像素 → 300 / (0.3/3) = 3000px
- 选用 5MP（2448×2048）或更高

**（2）传感器尺寸与像素尺寸**

- 常见尺寸：1/3" → 1/1.8" → 2/3" → 1" → 4/3"
- 像元尺寸：3.45μm（主流）→ 2.74μm（高分辨率）→ 5.5μm+（高灵敏度）
- **小像元** → 相同传感器面积放更多像素，但进光量少，暗光下噪声大
- **大像元** → 信噪比高，适合高速/低光场景

**（3）全局快门 vs 卷帘快门**

| 全局快门 | 卷帘快门 |
|---------|---------|
| 所有像素同时曝光 | 逐行曝光 |
| 运动场景无变形 | 运动场景产生果冻效应 |
| 价格高、像素稍低 | 价格低、像素高 |
| **运动检测首选** | 静止检测可用 |

### 2.3 接口与帧率

| 接口 | 带宽 | 典型帧率@5MP | 适用 |
|------|------|------------|------|
| GigE | 1Gbps | ~15fps | 低速、长距离（100m） |
| USB3.0 | 5Gbps | ~30fps | 通用、中等距离（3-5m） |
| Camera Link | 850MB/s | ~60fps+ | 高速、线阵 |
| CoaXPress | 6.25Gbps×n | 极高 | 高端应用 |
| 10GigE | 10Gbps | ~60fps+ | 高速+长距离 |

**节拍计算**：产线节拍 3s/件，扣除机械动作 1.5s → 采集+处理 ≤ 1.5s，帧率需求不高，USB3或GigE足够。

## 3. 镜头选型

### 3.1 焦距计算

```
焦距 = 工作距离 × 传感器尺寸 / 视野
     = WD × SensorSize / FOV
```

例：传感器 2/3"（8.8mm宽），视野 300mm，工作距离 500mm
- 焦距 = 500 × 8.8 / 300 ≈ 14.7mm → 选16mm或25mm

### 3.2 关键指标

- **分辨率**：镜头解析力须匹配像元尺寸（MTF曲线上判断）
- **畸变**：测量类应用 < 0.1%，检测类 < 1%
- **景深**：工件高度变化大于景深 → 需缩小光圈或增加工作距离
- **接口**：C口（法兰距17.5mm）和CS口（12.5mm），大传感器用F口/M42口
- **靶面**：镜头靶面 ≥ 传感器尺寸，否则有暗角

### 3.3 远心镜头

当工件有高度变化但需保持尺寸一致性时使用。特点：几乎无透视误差，但价格是普通镜头的5-20倍，且镜头口径必须大于视野。

## 4. 相机数量与工位布局

### 4.1 确定相机数量

```
相机数量 = 检测面数 × 每面所需视角数
```

**步骤**：
1. 列出所有待检表面（正面、背面、左/右侧面、顶面、底面）
2. 每个表面评估一个视角能否覆盖（考虑遮挡、景深、分辨率）
3. 曲面/复杂面 → 多视角拼合或切换不同角度光源

**常见配置参考**：

| 场景 | 相机数量 | 说明 |
|------|---------|------|
| 单面平面检测 | 1 | 最常见 |
| 双面（正+反） | 2 | 翻转机构或双工位 |
| 圆柱体外表面 | 3-4 | 环绕布置 |
| 汽车座椅 | 4-6 | 正面+背面+两侧+头枕+坐垫细节 |

### 4.2 摆放位置原则

**（1）工作距离**
- 太近：景深不足、工件可能碰撞镜头
- 太远：分辨率下降、占地面积大
- 典型：200-800mm，留出机械手/传送带余量

**（2）相机角度**
- 尽量垂直于检测面（正射），减少透视畸变
- 必须倾斜时，用沙姆定律调整焦平面（倾斜镜头/移轴）
- 避免镜面反射方向（入射角=反射角的位置会产生高光盲区）

**（3）多相机防干涉**
- 相邻相机间用遮光板隔离
- 分时触发：奇数帧触发A组相机，偶数帧触发B组
- 光源不可直射相邻工位的镜头

### 4.3 触发与同步

```
工件到位传感器 → PLC → 触发信号 → 光源控制器 + 相机（同步）
                                   ↓
                              相机曝光结束 → 采集卡/主机取图
```

- 光电开关/接近开关检测工件到位
- PLC或专用触发板输出同步脉冲给光源和相机
- 相机设为外触发模式（硬件触发），不是软件轮询

## 5. 选型决策流程（总结）

```
需求分析
├─ 待检缺陷类型 & 最小尺寸 → 确定分辨率
├─ 待检表面数量 & 朝向 → 确定相机数量 & 工位
├─ 产线节拍 & 运动状态 → 确定帧率 & 快门类型
├─ 表面材质 & 反光特性 → 确定光源类型 & 打光角度
├─ 颜色/波段对比度需求 → 确定光源波长
└─ 安装空间 & 工作距离 → 确定焦距 & 镜头类型

计算验证
├─ 分辨率 = FOV / (缺陷最小尺寸 / 3)
├─ 焦距 = WD × SensorWidth / FOV
├─ 帧率 ≥ 1 / (节拍 - 机械时间)
├─ 像元尺寸 ≥ 4.5 × 波长 / 光圈 (衍射极限校验)
└─ 景深 > 工件高度变化

方案评审
├─ 模拟打光（用样件实际搭建）
├─ 验证缺陷检出率（至少 50+ 样件，含各类缺陷）
└─ 验证误检率（100+ OK件连续运行）
```

## 6. 实战经验清单

1. **打光比选相机更重要**：先确定光源方案，再配相机。同样的相机在不同光下表现天差地别。
2. **样件实验不可跳过**：理论计算是起点，真实样件（包含各类缺陷+各类OK件）下的测试才是最终依据。至少留 10% 的边缘 case 做最终验收。
3. **偏振片是低成本降反光神器**：几十块钱的偏振片 + 偏振光源能解决大量高反光问题，不要一上来就上穹顶光。
4. **红色光源 + 红色滤镜**：在金属件检测中，组合使用可极大压制环境光干扰。
5. **遮光罩必须做**：产线现场的顶灯、窗户阳光、邻近工位灯光是误检的主要来源之一。遮光罩成本远低于后期调参。
6. **镜头分辨率要冗余 1.3 倍**：镜头标称分辨率是在最优光圈、中心区域测的，边缘和实际光圈下会下降，采购时留余量。
7. **相机像素不是越高越好**：高像素意味着小像元 → 需要更多进光量 → 需要更亮的光源或更长的曝光时间 → 影响节拍。在满足精度的前提下，选最低够用的分辨率。
8. **工业相机 ≠ 消费相机**：必须选工业级（Sony Pregius / Onsemi PYTHON / Gpixel 传感器），关键区别在于：全局快门、坏点控制、长时间稳定性、SDK可编程性、温度范围。
